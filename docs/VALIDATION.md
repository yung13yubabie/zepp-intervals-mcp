# 本版檢查紀錄

日期：2026-10-05。

這是公開教學範本的本機驗證；所有測試資料都由程式合成，沒有讀取任何人的 Intervals 帳戶或健康紀錄。

## 已檢查

- 使用附帶的 lockfile 重新安裝依賴
- 30 項合成測試：登入／擁有者拒絕、預設停用、固定 GET 路線、來源與欄位篩選、日期聲明、缺值、錯誤處理、回應與請求大小、分段飽和、公開範本、owner hash
- TypeScript 與 ESLint
- 公開範本掃描：Site 佔位符、空 Secret、停用開關、常見金鑰／私人檔案；同時檢查暫存區與工作檔
- 正式建置成功
- 人工核對不含真實 Site 身分、帳戶指紋、金鑰或健康匯出，以及第三方授權通知

執行環境是 Node.js 24.19.0。最低版本仍依套件宣告為 22.13.0；GitHub workflow 使用 Node.js 22，執行結果以各自 repo 的 Actions 頁為準。

## 這份檢查沒有證明什麼

- 沒有替讀者建立帳戶、登入 Zepp、取得 API key 或接受條款
- 沒有測試任何讀者的真實同步、欄位完整率、裝置相容性或私人 Site 設定
- 沒有將教學範本部署為公開健康服務
- 沒有用真實健康資料測試 CI，也不把合成測試當作端到端驗收
- 基本公開內容掃描不等於完整秘密偵測或安全認證

完成自己的設定後，仍應依 [從零設定](FROM_ZERO.md) 私下核對一筆活動及必要日指標。若程式、上游 API 或依賴改動，請重新檢查。
