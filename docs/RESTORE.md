# 備份與復原

## 要備份什麼

- 你正在使用的程式版本：保留 repo、commit，或 GitHub Download ZIP
- 你的非機密設定清單與步驟
- 你自己 Site 的識別與版本：只放私人紀錄，方便回到正確服務

不要把 API key、`.env`、`.dev.vars`、健康匯出、聊天紀錄、部署 token 或 owner hash 一起提交公開 repo。Secret 由你自己的安全設定／密碼管理方式保存。

## 只是換電腦

下載同一版 repo、安裝相同 lockfile 的依賴、跑 `npm run verify`。這不會改動已部署 Site，也不會自動帶回 Secret。要繼續操作既有 Site，先確認它仍在你的帳戶並使用它的正式來源開啟流程；不要任意建立同名服務當成原本那個。

## 要從頭建新的 Site

1. 從公開範本開始，不攜帶舊服務的部署識別或 Git 歷史
2. 讓 Sites 建立新的私人專案與插件
3. 重新計算自己登入帳戶的 owner hash
4. 自己填 Secret，先保持讀取停用
5. 儲存、重新部署，按教學先驗連線與設定，再小範圍讀取

新 Site 有自己的身份與插件。程式備份不能代替新的服務登錄、登入授權或 Secret 設定。

## 只想回退程式

在自己的 Site 歷史選擇已確認的保存版本，檢查目前環境設定及私人存取範圍，再要求部署該版本。舊程式可能遇到新設定；回退程式不保證 Secret 也回退。先停用資料讀取再排查比較安全。

## 清理舊檔前

先確認最終 repo 可開啟、重要檔案完整、你要保留的版本可下載。只刪不再需要的草稿或重複打包檔；不要因為有公開範本就刪除自己唯一的私人設定紀錄。公開範本不能還原你的金鑰、帳戶、健康資料或服務設定。
